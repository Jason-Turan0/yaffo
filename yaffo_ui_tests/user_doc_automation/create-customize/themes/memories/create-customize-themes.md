# Themes page notes

- The publish action in the draft banner is labeled **"Save draft"**, not "Publish"
  (button `themes_publish` posts from a `btn-primary` labelled `_("Save draft")`).
- The "Save draft"/"Discard" draft banner only renders when a custom theme has a
  READY working draft (`selected_has_draft`). The seeded Test Ocean theme is
  published/idle, so the theme-editor screenshot does NOT show the draft banner —
  a label change there does not change the screenshot pixels.
- THEMES (built-in) = Classic, Darkroom, Neo-Brutalist, Scrapbook, Photos App,
  Memphis (6 system themes). Prose list matches.
