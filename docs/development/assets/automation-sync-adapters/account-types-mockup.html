Design note
Check
the connection block's check call (/api/v1/accounts/verify_credentials) proves the token and yields the account id + label
Account id
account id from verify_credentials + server; a key with no such call falls back to a key fingerprint
Placement
header Authorization: Bearer … here; other services put it in a query parameter or the URL path, as declared; scripts never see it
